## 💻 Техническая информация

### Особенности сайта
- **Адаптивный дизайн** - корректно отображается на всех устройствах
- **SEO-оптимизация** - структурированные данные Schema.org, мета-теги

- HTML5, семантическая разметка
- CSS3 — собственные стили, без внешних библиотек
- JavaScript (ES-модули): данные в `js/content.js`, рендер разделов в `js/site.js`
- Локальные изображения и SVG-иконки
- Схема Schema.org для SEO

## 🚀 Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/[username]/romanov.git
cd romanov
```

2. Запустите локальный веб-сервер в папке проекта и откройте страницу в браузере:
```bash
python -m http.server 4173
# затем http://127.0.0.1:4173/
```

Важно: сайт использует ES-модули, поэтому простое открытие `index.html` двойным щелчком (через `file://`) не сработает — нужен локальный сервер.
